本站搭建笔记：免费二级域名 + 纯静态博客

建站2026-10-09 · 约 4 分钟

先说结论：这个博客从注册域名到上线，一分钱没花，总耗时不到一小时。2026 年了，免费顶级域名（当年的 .tk/.ml）早已成为历史，但免费二级域名 + 静态托管这条路依然畅通。

方案选型

免费域名的现实是：Freenom 在 2024 年退出之后，真正免费的顶级域名已经不存在了。剩下的靠谱选择是各大平台赠送的二级域名：

  • username.github.io—— GitHub Pages，适合程序员，博客生态（Jekyll/Hugo）最成熟；
  • xxx.pages.dev—— Cloudflare Pages，部署极快，国内访问速度不错；
  • xxx.vercel.app / xxx.netlify.app—— 同样免费，适合前端项目。

本站用的是纯手写 HTML + CSS，没有构建步骤，拖到任何一个平台都能直接跑。

本站的技术栈

  • 纯静态页面：HTML + 一个 style.css，零依赖、零构建；
  • 深色 tech 风主题：藏青底 + 香蕉黄点缀，和公众号文章的视觉体系呼应；
  • 响应式排版，手机和电脑都能舒服地读。

怎么更新文章

在 posts/ 目录下复制一篇旧文章的 HTML，改标题和正文，然后在首页 index.html 加一张卡片链接过去，重新部署即可。全程不需要数据库、不需要后台。

博客的本质是写作，不是折腾工具。工具越简单，写得越多。

如果你也想搭一个，照着这个思路走就行——先有个地方写，比写在哪里重要得多。
